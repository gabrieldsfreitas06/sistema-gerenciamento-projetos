# Sistema desenvolvido em Java utilizando Programação Orientada a Objetos (POO).

O projeto simula um ambiente de gestão de projetos com três níveis de acesso:

• Administrador
• Gerente de Projetos
• Colaborador

# Funcionalidades:

Cadastro de projetos, Cadastro de equipes, Cadastro de colaboradores, Criação de tarefas, Atualização de status dos projetos, Controle de andamento das tarefas, Consulta de informações dos projetos, Visualização de equipes responsáveis
 
# Tecnologias utilizadas:

- Java
- IntelliJ IDEA
- Programação Orientada a Objetos
- ArrayList
- Scanner
